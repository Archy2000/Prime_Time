# 水体音效

## 鲨鱼游动降噪

WASD 游动改用 `SharkGlide.wav`：从平静水面素材制作的柔和低频水流循环，削弱高频拍水与低频轰鸣，接缝交叉淡化。生成脚本 `tools/build_shark_glide.py`。移除移动时每隔约 0.3 秒重复的小水花；普通游动和冲刺均不再触发激流水声。游动增益由 0.29 降为 0.10，冲刺上限 0.12，音高只作轻微变化。翻涌仅用于落水和造浪，重物入水音效保留。该循环替换运行时的 WaterFlowing，预加载数量仍为 23。

## 重物落水修正

鲨鱼落水使用 3 段专用 `WaterHeavyEntry`，不再复用跃出时的中型水花。由原水花降速分层、短促低频水腔冲击、延迟的水体回落翻涌和气泡合成；低频成分为程序合成，不是原游戏的重物入水录音。生成脚本为 `tools/build_heavy_water.py`，先运行原音频导出脚本再运行此脚本即可重建。

体型越大，落水音高越低；下落越快，冲击越强。单段约 3 秒，运行时根据体型进一步调整播放速度。滴水推迟并降低 4dB，避免入水瞬间听起来像小水滴。普通游动、碎块水花和跃出继续使用原配置。新增后共 23 段音频；重物素材峰值上限 0.88，保留 Water 总线限幅。

20 段音频来自本机 Sandcastle Demo，来源路径、Unity Path ID 和解码后源文件 SHA256 记录于 `research/water_audio_sources.json`。这是本地参考原型的素材移植与玩法混音适配，并非恢复原游戏的音频驱动代码；素材权利仍属于原权利人。

`tools/extract_water_audio.py` 可从原安装重新导出。环境保留立体声；空间水花合并为单声道；循环接缝使用 180ms 交叉淡化；瞬态做 4ms 边缘淡化，峰值不超过 0.8。

运行配置：`scripts/water_audio.gd`。

- WaterCalm_02：持续环境底声，默认线性增益 0.035（从 0.20 下调约 15dB，让静止时仅保留轻微水面氛围）。
- WaterFlowing：游动流水，按水平速度渐变，增益上限 0.29。
- WaterAgitated_01：高速游动、冲刺、落水后翻涌和试验场 Q 海浪，增益上限 0.32。
- WaterSplashSmall ×5：游动及轻水花，按距离与速度调节。
- WaterSplashMedium ×4：大水花、跃出和落水，按体型、垂直速度调整音高与强度。
- Bubble ×3、WaterDrop ×5：落水后的气泡与错开的滴水尾音。

F7 切换水声静音。主增益 `water_volume_db` 与三个循环增益均可在脚本导出属性中调整。Water Ambient / Water Motion / Water Impacts 汇入 Water 总线，使用 -2dB 限幅。总线仅初始化一次。瞬态音源池上限 16，碎块落水间隔至少 65ms，跃出／落水优先保留一个声道，随机轮换不连续重复。空间音源最大距离 65m，监听位置在玩家上方，朝向随镜头。

暂停冻结循环与事件尾音，切场景自动释放节点；无水模式静音。城市与水体试验场共用实现。环境底声是场景氛围，不是逐个岸线的声学模拟。

验证：`scripts/test_water_audio.gd`；结果 `research/water_audio_tests.json`。测试覆盖素材加载、循环启动、监听位置、落水尾音、并发限流、游动和静止音量响应、暂停、无水静音、场景切换和试验场海浪。
