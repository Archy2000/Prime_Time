# 白沫修改前后对比

- `comparison.mp4`：左修改前 V09，右修改后 V10，8 秒同步并排视频，无音轨。
- `before.mp4` / `after.mp4`：各自 1280×720 原分辨率录制。
- `before/city.png` / `after/city.png`：同一时刻的城市游动截图。
- `before/npc.png` / `after/npc.png`：大鲨鱼开始运动前，仅小 NPC 游动时的截图。
- `before/settled.png` / `after/settled.png`：停下后同一时刻的残留截图。

场景、镜头、光照、滤镜、初始水位、时间步、8 个 NPC 的模型/位置/运动路径均一致。NPC 水体尺度 0.35，视觉尾浪尺度 0.30；鲨鱼体型 2.69，游速 9.5m/s，沿同一路线前进后停止。录制预热 6 秒，再按 30Hz 模拟、15fps 输出 120 帧，录像中后半段可检查白沫消退。

为了可重复，角色姿态和位移由脚本控制，不执行吞噬、碰撞移动和随机互动。因此这是同条件视觉对照，不是两次手动游玩的随机录像。真实白沫、尾浪、飞沫和水面均由游戏渲染，截图未修饰。视频只缩放并排并加版本标题。修改前使用 `research/v10_before/` 冻结的求解器、异步封装、白沫材质和尾浪脚本，不是用新版参数冒充旧版。

## 调整

1. 小于网格分辨率的扰动使用面积补偿，小 NPC 不再凭借最小数值半径产生大体积波浪；小体型注入力同步减小。
2. NPC 的精细尾沫寿命 1.65→0.55 秒，宽度和透明度收紧；1× 及以上角色保留原精细尾浪宽度和寿命。
3. 持续白沫衰减系数 0.48→1.05/s；破浪源和撞击源降低，短时撞击包络仍用于飞沫。
4. 物体接触带从最多约 0.28m 收到最多约 0.11m；保留断续窄白边，移除底层泛白混色。
5. 限制远景泡沫抗锯齿宽度，防止小噪声在低屏幕分辨率下变成大片白色。

## 验证

`../v10_scale_tests.json`：相同 0.8m/s 游速、连续 3 秒注入，小 NPC 最大波高由约 0.159m 降为约 0.00167m；仍有非零波动，并有独立精细尾沫。这是隔离平水实验的求解器数值，不是所有实际场景都按固定比例减弱。

`../v10_solver_tests.json`：静水稳定、白沫平移、墙体阻断通过。

`../v10_surf_tests.json`：有入射波时仍产生撞击白沫，静止墙体不产泡，白沫消退与干区清除通过。

`../v10_breach_tests.json`：1× / 3.2× 体型的跃出、落水、放大、暂停与回收通过。
