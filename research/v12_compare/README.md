# V11 → V12：从白边改为独立泡沫片

本轮重新解压并反汇编了参考项目的白沫 **绘制** 着色器。证据见 `../sand_water/whitewater_render/READOUT.md`；之前仅掌握模拟结构，V11 连续接触白边不符合原作圆片实例绘制方式。

V12 删除了八方向屏幕深度白边，改为独立的软边圆片成簇出现。每个圆片有位置、状态和尺寸；随局部水流移动、缩小和消退。NPC 白沫集中在两侧约身体宽度附近，物体白沫由实际碰撞位置发射。大鲨鱼尾浪、水色、折射及焦散继续保留。

- `comparison.mp4`：左 V11、右 V12；V11 帧复用上一轮原始录制，V12 使用相同镜头、路径及可见角色安排。
- `before/objects.png` / `after/objects.png`：同一个水场与镜头，只切换旧白边 / 新粒子显示方式，便于观察泡团形状。
- `after/npc.png`：小 NPC 游动阶段；`after/city.png`：大鲨鱼游动阶段。
- `before/capture.json` 的 after 是上一轮录制标签，实际是 V11。

验证：`../v12_particles_tests.json` 检查运动发射、局部范围、停止后消退、静止不发射、1200 数量上限和水位同步；`../v12_contact_tests.json` 检查场景碰撞发射与存活粒子；`../v12_breach.log` 检查原跃出落水行为。画面人工检查为稀疏亮泡团，不能用“有粒子”测试代替与参考图的美术验收。

这是按新证据重建的粒子绘制方案，仍不是原作完整源码或逐像素复刻。岸边沙地、水下模型和光照与参考项目不同；原作完整生成规则尚未恢复。
