1 INTRODUCTION
This documentation provides a comprehensive guide for integrating the PS1-Styled
Great White Shark into your development pipeline. It details the directory structures,
and the strict technical rendering specifications required to maintain an authentic PS1
aesthetic. Furthermore, it outlines step-by-step engine configurations for Unity, Unreal
Engine, and Godot. An exhaustive visual catalog of all included assets is provided at the
end of this document for quick reference
2 CONTENT AND WORKFLOW
The geometry and textures are developed natively in Blender 5.0.1. The work-
flow ensures low polygon counts and vertex snapping compatibility characteristic of the
targeted aesthetic.
2.1 Directory Structure
The package is organized into specific directories for optimized access.
Table 1: Correlation between folder names and their contents.

mise the pixelated aesthetic. To maintain the intended PS1 aesthetic and ensure seamless
integration across different game engines, adhere to the following technical parameters:
Table 2: Recommended import and rendering settings.

3.1 Engine-Specific Configuration
The following configurations must be applied to every texture imported from this
package. Default engine settings apply interpolation and compression that are incompat-
ible with the PS1 aesthetic.
3.1.1 Unity
Select the texture asset in the Project panel. In the Inspector, apply the following
settings underTexture Import Settings:
Filter Mode: Point (no filter)
Generate Mip Maps:Disabled
Compression: None
Max Size:Match the original texture resolution (maximum 256)
For mesh shading, select the mesh and underModel→Normals, setSmoothing
Angleto 0.
3
3.1.2 Unreal Engine
Double-click the texture asset to open the Texture Editor. Apply the following
settings in theDetailspanel:
Filter: Nearest
Mip Gen Settings: NoMipmaps
Compression Settings: UserInterface2D (RGBA)or TC EditorIconto
avoid lossy compression
sRGB:Enabled (default)
For flat shading, set the Static MeshLOD→Normal Import Methodto
Import Normalsand ensure no smoothing groups are applied on export from Blender.
3.1.3 Godot
Select the texture file in the FileSystem dock and open theImporttab. Apply
the following settings, then clickReimport:
Filter:Disabled (corresponds to Nearestfiltering)
Mipmaps→Generate:Disabled
Compress→Mode: Losslessor Uncompressed
Alternatively, set theTexture Filterproperty directly on theMeshInstance3D
material to Nearestto override globally without reimporting each texture.
