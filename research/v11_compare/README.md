# V10 → V11：局部白沫

`comparison.mp4` 为同步并排对比（左 V10、右 V11）。城市条件沿用 V10 的固定镜头、8 个 NPC、相同运动与 2.69× 鲨鱼；V10 原始帧直接来自上轮 `v10_compare/after/`，没有重新修饰。V11 由 `tools/compare_foam_v11.gd` 同条件录制。`before/capture.json` 中的 after 是上一轮录制标签，版本实际为 V10。

- `after/npc.png`：慢游阶段，人物周围的局部短白弧。
- `after/city.png`：同一游动时刻，建筑白沫与鲨鱼尾流。
- `before/objects.png`、`after/objects.png`：冻结相同水高 / 流速与镜头，只替换材质的岩石 / 横墙近景。

## 改动

NPC 的触发速度从 0.6 降到 0.12m/s；亮度达到常规值所需的速度从鲨鱼用的 5–6m/s 改为 0.65m/s。采样间距缩至 0.035m，避免慢游时短尾沫只有一个点、无法形成网格。尾迹宽度仍按 0.30 体型计算，生命约 0.75s；1× 及以上角色的阈值 / 寿命维持原值。

物体白沫增加八方向屏幕深度邻域采样。邻近几何必须达到局部水面高度，且距当前水面点小于约 0.48m，才能形成接触带；检测范围由世界尺度换算并限制到 1.5–4 个像素。白沫沿真实渲染边缘出现，噪声打断连续白线，流速 / 撞击包络增强亮度。该方法只处理可见几何，仍是渲染近似，不是参考项目完整三维流体源码复刻。
