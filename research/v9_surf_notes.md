# V9 海浪 / 白沫优化

## 参考证据与边界

参考用户截图及本机 `D:\SteamLibrary\steamapps\common\Sandcastle Demo`。本轮复用并重新检查项目已有的本机资源提取和反汇编结果：

- `sand_water/636_Water_constants.json`：水网格分辨率、单元大小、重力、阻尼、平流和波幅等独立参数。
- `sand_water/647_Whitewater_Update.asm.txt`：读取四个相邻 waterCells 并插值；状态按 deltaTime 更新位置和衰减。可以确认独立、随水流更新的白沫状态，但未据此声称恢复全部压缩字段含义或原生成公式。
- `sand_water/587_Lit_Water.shader.txt` 与 `water_source.json`：原水体使用法线贴图、透明渲染和折射属性；导出的文本不含有效原 HLSL。

动态水高是运行时模拟场，不能用一张静态高度贴图替代。本轮没有新提取美术贴图，继续使用已有原法线和项目焦散资源。新的白沫细节由着色器程序生成。

## 实现

`water_hydro.gd` 保持原水高 / 速度通量方程。新增撞击强度场：朝向固体的入流与局部水位上升共同产生撞击；浅水流速产生破浪；陡峭正浪峰产生少量白沫。固体邻域使用流体侧高度计算坡度，避免把墙本身当成陡浪。白沫平流后以约 1.44 秒半衰期消退，干区清除；撞击包络更快衰减。

RGBA 高度纹理仍为高度 / 地面 / 白沫 / 固体。流速纹理 A 通道增加撞击强度，异步版本只上传完成的快照。水高方程不变，避免现有浮力和跃出水面的位置产生额外视觉偏移。

`water_v3.gdshader` 增加同场坡度明暗、流动碎泡、抗锯齿阈值及按世界空间水深变化的接触带。强白沫集中在浪头 / 浅滩，细小残泡跟随流场退散。

`wake_fx.gd` 每 0.14 秒从完成的快照分批采样有效撞击，限制为可见固体边缘、每批最多 12 滴，现有飞沫超过 96 时停止额外生成。仅视觉飞沫，不反复向求解器加能量或播放大量重复撞水音效。

## 验证

- `v9_solver.log`：既有静水稳定、泡沫平移、无墙传播 / 有墙阻断通过。
- `v9_surf_tests.json`：静止墙边白沫为 0；有入射波时撞击包络与白沫显著大于 0；5 秒后泡沫低于初始 15%；干区泡沫为 0；水高保持有限。
- `v9_breach.log`：1× / 3.2× 鲨鱼跃出 / 落水、生成数量上限、体型放大、暂停、回收均通过。
- `v9_render.log`：实际 OpenGL 渲染生成三张近景；注入波列后产生撞击飞沫，末帧已回收。截图 `v9_surf_059.png`、`v9_surf_149.png`、`v9_surf_269.png`。近景测试主动造浪以观察岩石 / 横墙效果。
- `v9_city.log`：城市游动、冲刺、停止后尾浪回收和有限水高回归。静止后仍可能有自然撞浪飞沫，这是独立于角色尾浪的预期行为。

性能观察：单独运行城市回归时末段约 18 FPS（RTX 4060 / 当前完整城市场景），本轮不是性能优化完成的证明，也没有旧版同条件城市 FPS 对照。浅水试验场末次求解约 30 ms，原版同场景记录约 24 ms；新增白沫计算有 CPU 成本，仍由后台线程执行。后续若要求稳定 60 FPS，需要单独分析城市场景与求解器负载。

旧实现和同场景截图保留于 `v9_before/`。采样网格仍为 160×160，城市建筑仍采用 AABB 障碍近似；物体边缘精度受此限制。着色器不能实现三维翻卷浪；本版也没有砂土侵蚀。线程模拟有固定步长和积压限制，慢机器上模拟时钟可能落后实际时间。
